# 鍵盤按鍵診斷工具

免費線上鍵盤按鍵測試工具，單頁 HTML + CSS + JavaScript，不需安裝、不需後端。

🔗 線上版本：<https://ivantw829.github.io/keyboard-test/>

## 功能

- 直接按下實體鍵盤，畫面會即時在對應按鍵上計數（以實體按鍵位置判斷，不受 Shift、Caps Lock、輸入法影響，可分辨左右修飾鍵）
- 連點偵測：同一顆鍵在 80 毫秒內重複觸發會自動標示（橘色驚嘆號）
- 點擊畫面上的按鍵可手動標記為「故障」（紅色驚嘆號）
- 測試進度：顯示已測試鍵數與疑似故障鍵數
- Mac / Windows（ANSI）佈局切換，首次開啟依系統自動選擇
- 深色／淺色／跟隨系統主題切換
- 響應式版面，可在較小的螢幕上使用
- 一鍵重設所有計數與標記

## 使用方式

用瀏覽器打開 `index.html` 即可，或直接訪問線上版本。

## 技術

純前端（HTML/CSS/JavaScript），由 Grok 4 協助開發，提供 Mac / Windows（ANSI）佈局。
