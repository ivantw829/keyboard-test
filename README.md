# 鍵盤按鍵診斷工具

> 本專案已 Archive，保留供參考，程式碼不再更新。

免費線上鍵盤按鍵測試工具，單頁 HTML + CSS + JavaScript，不需安裝、不需後端。

🔗 線上版本：<https://keyboard.ouoc.net/>

## 功能

- 直接按下實體鍵盤，畫面會即時在對應按鍵上計數
- 點擊畫面上的按鍵可標記為「故障」（紅色驚嘆號）
- 深色／淺色主題切換
- 一鍵重設所有計數與標記

## 使用方式

用瀏覽器打開 `index.html` 即可，或直接訪問線上版本。

## 技術

純前端（HTML/CSS/JavaScript），由 Grok 4 協助開發，適用於 macOS。
